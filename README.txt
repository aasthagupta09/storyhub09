STORYHUB - SIMPLE JAVA MINI PROJECT

Folder structure:

StoryHub
|-- frontend
|   |-- index.html
|   |-- style.css
|   `-- script.js
|
`-- backend
    `-- StoryHubBackend.java

FRONTEND:
Only HTML, CSS and JavaScript.

Features:
- Home page
- Story categories
- Search
- Read stories
- Write and publish stories
- Rating
- Favourite stories

BACKEND:
One simple Java file.

Java concepts used:
- Class and object
- Constructor
- ArrayList
- Methods
- Scanner
- switch-case
- Basic searching
- Rating

HOW TO RUN FRONTEND:
1. Open the frontend folder.
2. Open index.html in a browser.
3. You can use VS Code Live Server if installed.

HOW TO RUN JAVA BACKEND:
Open terminal inside backend folder.

javac StoryHubBackend.java
java StoryHubBackend

IMPORTANT:
This version is intentionally simple for a college mini project.
The frontend is a browser-based demo and the Java backend is a separate basic Java console backend, so there are no Servlets, Spring Boot, Maven or database complications.
